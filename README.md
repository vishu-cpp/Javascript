# JavaScript Learning Journey 🚀

Welcome to my JavaScript learning repository! This project serves as a personal knowledge base and collection of core JavaScript concepts, code snippets, and explanations. It is designed to help understand the fundamentals of JavaScript in a practical way.

## 📁 Repository Structure

Here is a breakdown of the topics currently covered in this repository:

- **[`datatype.js`](./datatype.js)**
  A deep dive into JavaScript data types. It covers both primitive (String, Number, Boolean, Null, Undefined, Symbol, BigInt) and non-primitive (Object, Array, Function) types. It also demonstrates how comparison and relational operators process `null` and `undefined`.

- **[`hoisting.js`](./hoisting.js)**
  Explains the concept of Hoisting in JavaScript. It includes practical examples comparing the hoisting behavior of `var`, `let`, `const`, and function declarations, along with a detailed explanation of the Temporal Dead Zone (TDZ).

- **[`stack&heap.js`](./stack&heap.js)**
  Illustrates how JavaScript manages memory. It shows the difference between Stack memory (used for primitive data types) and Heap memory (used for non-primitive data types/objects), and how references origin are handled when variables are reassigned.

- **[`Basics.js`](./Basics.js)**
  A placeholder for foundational JavaScript concepts (Work in Progress).

- **[`page.html`](./page.html)**
  A basic HTML boilerplate to run and test these JavaScript files directly in the browser's console.

## 🚀 How to Use

To explore the concepts:

1. Clone the repository to your local machine.
2. Open the individual `.js` files using a code editor (like VS Code) to read the explanations and code examples.
3. You can execute these scripts using Node.js in your terminal:
   ```bash
   node datatype.js
   ```
4. Alternatively, open `page.html` in your web browser and check the developer console (F12) to see the output of the linked scripts.

## 🛠️ Concepts Covered

- Primitive vs Reference data types
- Type conversion and coercion quirks (`null` comparisons)
- Execution Context & Hoisting
- Scope (Block vs Global) and Temporal Dead Zone (TDZ)
- Memory Allocation (Stack vs Heap)
